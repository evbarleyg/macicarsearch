## 5. Tooling gotchas, learned the hard way

- **`update_draft` silently strips reply threading.** It rebuilds the message. To revise a
  threaded reply you must `create_draft` again with `replyToMessageId` and retire the old one.
- **`update_draft` cannot clear recipients.** Passing empty `to`/`cc` arrays does nothing.
  Subject and body are the only fields that stick. Retire dead drafts by retitling them
  `DELETE ME`; there is no delete tool. Evan bulk-deletes by searching `subject:"DELETE ME"`.
- **Gmail search goes stale.** It served a >1 hour old copy of the Kirkland thread and caused a
  false "it never sent" report. **For active threads, fetch by thread ID with `get_thread`.**
- **The connector cannot download attachments.** Dealer PDFs must be opened by Evan or uploaded
  to chat. Scanned PDFs have no text layer: `pdftotext` returns nothing, so use the Read tool
  with `pages` to render them visually. That is how both Puyallup worksheets and the Kirkland
  proposal were parsed.
- **Egress proxy blocks** every listing site, every dealer site, `fileproxy.drivecentric.io`,
  becu.org, edmunds, and github.io. Verify site deploys through the GitHub Actions API instead
  of fetching the page.
- **Bash cwd resets between calls.** Always `cd /home/user/macicarsearch` first.
- **Dealer mail lands in Promotions and sometimes spam.** `bilorih@dagpuyallup.com` sat in spam
  for ~25 hours and evaded every domain filter. Sweep broadly by name and keyword, not just domain.
  Label dealer threads `Label_33` ("CX-5 dealers").

## 6. Repo layout and the publish pipeline

- **`claude/dealership-outreach-emails-8sp5zh`** — the tracking branch. `outreach/README.md` is
  the append-only contact log. This file lives here too.
- **`main`** — the public site, deployed to https://evbarleyg.github.io/macicarsearch/
- **`outreach`** — Mac-session relay branch. Ingest pushes here before acting.

**The site is generated. Never hand-edit `index.html`, `status.html`, `map.html`, `trims.html`,
`ask.html` or the xlsx/docx/pdf downloads.** Edit `data/board.json`, then:

```
python3 tools/build_site.py
grep -RInE "28,123|27,600|26,500|30,127|31,957|32,194" index.html status.html map.html trims.html ask.html
```

The grep must come back empty. Then commit both `data/board.json` and the generated files.

Neutrality is enforced at the render layer: quoted rows show an *estimate* with a "quoted" chip,
`quoted_selling()` returns None, the calculator always runs in estimate mode, and
`model_for_downloads()` deep-copies and nulls every quote and counter. The Pages workflows
`rm -rf outreach` before upload so the log can never reach the site.

**The repo is PUBLIC.** The contact log is therefore publicly readable. Evan knows and accepts this.
`deal-desk.html` is committed with page-level `noindex` and an explicit robots.txt disallow;
robots.txt already blocks the whole site.

Note: the `#1`-`#21` car numbers are **Aug 7 screening IDs**, not a preference order. They rank
listing data only. The cost table carries live standings.
